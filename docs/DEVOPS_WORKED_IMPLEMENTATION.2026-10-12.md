# DevOps 요약과 실제 개발 경로 보강

사용자는 요약의 `그림의 화살표`가 DevOps 정보 대신 도해 안내라고 지적하고,
어떻게 개발하는지 부족하다고 했다. 요약에서 해당 항목을 제거하고 같은 상품 정렬
예제를 실제 로컬 API·검사·결과물·버전 교체와 복구까지 이어지는 실습으로 보강했다.
최종 원고는 r11이며 r9와 중간 로컬 r10을 새 불변 배치로 보존한다.

## 독자 질문과 수정

독자는 DevOps 입문자이며 Git/CI 용어를 미리 안다고 가정하지 않는다.
실행 실습에는 Python 함수·목록·import를 읽을 수 있다는 준비 조건을 명시했다.
완성 결과는 정렬 API와12개 테스트, `.pyz` 버전 파일 및 실제 요청과 복구 확인이다.

| 질문 | 본문의 답 | 확인 범위 |
| --- | --- | --- |
| 개발과 운영이 무엇을 먼저 정하는가 | 5장 입력 규칙, 성공/오류 응답, 실행 조건과 복구 방법 | 학습용 가상 서비스의 합의 예시 |
| 코드는 어디에 어떻게 만드는가 | 파일 구조, 입력 검증/정렬, HTTP 처리, 버전 표시의 전체 코드 | 실행 코드와 본문 코드 정확히 일치 |
| 검사와 자동화는 어떻게 연결하는가 | 8개 함수/입력 +4개 HTTP 테스트, 같은 명령의 CI 설정 | 로컬 정상·실패·복원 실행; 원격 설정은 미실행 |
| 무엇을 배포할 것인가 | build.py의 zipapp 생성, 버전 식별과 SHA256 | 파일 생성 및 실제 파일 프로세스의 요청 확인 |
| 시험과 복구는 어떻게 하는가 | smoke, 두 명령창 요청, v1/v2와 저장한 v1 복구 | 실제 로컬 HTTP와 PowerShell 요청; 버전 표기만 다른 교체 연습 |
| 다른 기능으로 바꾸려면 | 높은 가격부터 정렬하는 코드와 함수/HTTP/smoke 기대값 | 변형 과제의12개 테스트와 실행 파일 요청까지 실행 |
| 남은 운영 작업은 무엇인가 | 운영용 서버/TLS/권한/비밀 값/재시작/트래픽 전환/DB 호환성 | 구현해야 할 조건의 설명; 운영 서비스 구축은 미실행 |

6장은 가격 누락을 이미400으로 처리하는 새 예제와 맞춰 클라이언트 입력 계약
불일치의 조사·완화·재발 방지로 바꿨다.9장의 검사 범위 및5개 과제/풀이도 맞췄다.
요약의 도해 안내는 삭제하되 접근성용 그림 설명과 이미지 바이트는 그대로 보존한다.

## 검토 과정과 발견한 결함

제목·소개·deck·요약만 별도 파일에서 읽는 자체검토와 전체 실습/출처 검토를
분리했다. 소개에 작은 **로컬** 서비스라는 실행 범위를 추가했다.
원격 CI 예시와 로컬 실행, 운영 환경 구축/성과 및 사람 독해 시험을 구분한다.

r10을 로컬 적용한 뒤 실제 페이지에서2장에 남은 “함수와 테스트만 실행” 문장을
발견했다. r11에서 API·결과물·복구 범위로 고쳤다. 기존 렌더는 모든 코드와 명령을
접어 두므로 최종 판의5장에만 기본 펼침을 연결했다. `expanded_code_chapters`는
보고서 hash에 묶인 visual guide 설정이다. 본문 schema v1과 이전 판의 접힘은 유지한다.
이 결함은 r10의 기계적 gate 통과로 해결된 것이 아니며 최종 원고/렌더에서 다시 확인했다.

## 원문과 날짜

기존19 원문 텍스트/hash/수집일과 기업·조사 수치, 기존 실패·미검토 기록을 보존했다.
새4개 공식 문서에서 아래 절을 선별 읽었다. 원문 전체/부록 정독이나 원격 실행을
주장하지 않으며 원문 갱신일은 별도 확정하지 않았다.

- [Python HTTP](https://docs.python.org/3.12/library/http.server.html): HTTPServer/요청 처리/응답과 운영용 부적합.
- [Python zipapp](https://docs.python.org/3.12/library/zipapp.html): create_archive/main/실행기 필요 조건.
- [GitHub artifacts](https://docs.github.com/en/actions/tutorials/store-and-share-data): 결과물 저장/전달과 보관 조건.
- [GitHub contexts](https://docs.github.com/en/actions/reference/workflows-and-actions/contexts): github.sha와 실행 이벤트.

실제 확보 시각과 raw byte/hash는 `data/raw/devops-2026-10-12/r10/sources.json`,
선별 내용 검토 시각은 r10/r11 quality sidecar에 있다. 캐시 재사용과 HTML 재생성은
새 원문 확인으로 바꾸지 않는다.
