## 상세 창의 소수 정밀도 오류 재현과 수정

첫 배포 `f67f92c` / [Pages39000697798](https://github.com/Hansihoo/signal-desk/actions/runs/39000697798)는 성공했고 공개 JSON 및 5개 소개, 전체 비교표/목록의 내용·보존 검사는 통과했다. 이후 실제 비교표에서 FLUX API의 0.009 USD가 상세 창에서 0.01로 표시되는 오류를 발견해 완료 처리를 보류했다.

첫 잘못된 상태는 `model_ledger.js`의 숫자 표시 단계다. 표는 `official:출력 USD / 이미지` 같은 표시 별칭을 전달하고 상세 창과 이전 판은 원래 필드 이름을 전달했다. 공식 수치를 20자리까지 보존하는 분기가 별칭만 인식해서 원래 이름의 가격과 평가값은 일반 2자리 반올림으로 들어갔다. 원본·SQLite·공개 JSON은 0.009로 보존돼 있었다.

표시 함수 입구에서 같은 공식 필드의 원래 이름과 별칭을 하나의 키로 정규화했다. 이로써 상세와 이전 판도 동일한 정밀도/단위 표시를 사용한다. 원본 수치를 고치거나 데이터 판을 새로 만들지 않았다.

실제 제공 JS의 선언과 표시 함수를 Node로 실행하는 회귀 시험을 추가했다. 수정 전에는 0.009가 0.01, 0.757이 0.76으로 나와 실패했다. 수정 후에는 표/원래 필드 모두 0.009 및 0.757을 보존하며 0, 미확인, 문맥 정수와 파라미터 표기도 통과했다. 관련 모델 원장 11시험과 로컬 publish가 통과했다. 실제 공개 재검증 결과는 아래에 추가한다.
