## 평가와 비용

- Beam은 초기 프리뷰 경쟁 표와 최종 정밀도 표를 분리했다. NVFP4 Terminal 값은 공식 카드 78.4와 HF 글 78.2의 차이를 남겼다. 501.3B 전체와 23.4B 활성 및 1,048,576 설정을 구분했다.
- Granite의 Decision Index는 v0.3 fast 1,068행, 0–100 기준이다. Guardian 전문 어댑터의 0–1 F1/균형 정확도와 Switch 전체 대화 능력을 합치지 않았다. 음성은 Alpha 전사 후 LLM 경로다.

- Jais 7B/375B의 같은 카드 경쟁 표에서 Arabic MMLU와 AraGen, AA-LCR, Terminal 및 offline SWE의 반대 결과를 보존했다. high 추론과 언어별 temperature, Avg@3/Pass@1을 구분했다.

표준 API 단가를 찾지 못한 모델은 미확인으로 남겼다. 공개 가중치와 무료 서버 운영, 활성 계산량과 전체 메모리를 동일시하지 않는다.
