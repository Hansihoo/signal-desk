# DevOps 본문에서 편집·사이트 안내 문구 제거

사용자는 `검토 의견` 같은 문구가 DevOps를 배우는 데 필요하지 않고 가독성을
떨어뜨린다고 지적했다. 최종 로컬 r12는 설명과 구현 과정, 자료의 의미와 기술 조건을
남기고 소제목 분류 배지와 편집·수집·검수 과정의 문장을 제거한다.

원인은 보고서의 내부 `kind` 분류를 공통 `_authored_blocks`가 매 소제목 옆에
자동 출력한 것이다. 데이터의 분류를 바꾸거나 CSS로 가리지 않고, 렌더 호출에서
배지와 반복되는 `근거` 접두어를 출력하지 않도록 수정했다. 현재 r12에만 적용되는
`reader_content_only`는 visual guide의 보고서 hash와 연결된다. 다른 보고서와 과거
판의 표시 및 기존 호출의 기본 동작은 유지한다.

- 분류 배지68개와 반복 근거 접두어51개 제거. 번호 출처 링크는 그대로 연결한다.
- 참고자료23개의 설명을 수집 날짜·403·선별 검수 이력에서 원문의 학습 내용으로 수정.
- `검토 범위`를 기술적인 `적용 범위와 한계`로 바꾸고 판 변경·검수 과정과 사람 시험 문구 제거.
- 장의 내용을 소개하는 반복 안내와 지표 표의 작성자 확인일 제거. 정의 갱신일과 조사 기간은 유지.
- 가상 상품 서비스라는 전제, 로컬 학습용 서버, 원격 CI 설정 예시와 무중단이 아닌 교체,
  설문의 대상·기간·인과 해석 한계는 실제 설명으로 유지.

본문과 참고자료를 읽고 기존23개 출처의 의미와 대조했다. 새로운 기술 주장이나
수치를 추가하지 않으므로 새 원문 수집은 하지 않았다. 원문 URL·text/hash·실제 수집
및 내용 검토 시각은 기존 품질 패키지와 기록에 그대로 남는다. 같은 에이전트의 별도
의미·가독성 검토이며 독립 검토나 사람 독해 시험을 수행한 것은 아니다.
