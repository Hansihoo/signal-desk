# AI로 문서를 활용하는 기능 조사

2026-10-23 사용자 요청으로 추가한 조사 범위다. Microsoft Office Copilot 같은
제품에서 AI가 실제 문서 작업을 어떻게 바꾸는지 매일 확인한다. 모델 성능이나
경쟁사 전략만으로 이 범위를 대신하지 않는다. 일일 출처·접근 모드는
[준비 목록](../config/daily_research_sources.json), 공통 발견·알림·날짜·중복 기준은
[발견 운영](SIGNAL_DISCOVERY.md)을 따른다.

## 매일 확인할 문서 작업

| 작업 | 의미 있는 변화 |
| --- | --- |
| 작성·편집 | 문서 초안/재작성, 자연어로 실제 본문·서식 편집, 변경 검토·되돌리기, 템플릿·브랜드 적용 |
| 표·데이터 분석 | 스프레드시트 수식·표·피벗·차트 생성/수정, 데이터 정리·분석, 결과를 워크북에 반영하는 범위 |
| 발표자료 | 자료에서 슬라이드 생성, 기존 발표 편집, 출처·디자인·브랜드와 결과 파일 보존 |
| 읽기·이해 | 긴 문서·PDF·계약 비교, 요약/질의응답, 인용·근거 추적, 여러 파일을 함께 읽는 범위 |
| 검색·재사용 | 조직/개인 자료 검색, 노트·지식베이스에서 문서 생성, Drive/SharePoint 등 저장소 연결과 권한 |
| 구조화·연결 | OCR·표/이미지/텍스트 추출, 변환·분류·업무 시스템 연결, 지원 파일·레이아웃·언어의 제약 |
| 협업·관리 | 공동편집, 승인·공유, AI 대화 이력·감사·보존, 관리자 정책·외부 모델/데이터 처리 조건 |

단순한 UI 색상·오탈자·버전 번호보다 사용 가능한 작업의 변화, 큰 품질/비용 차이,
제공 확대/축소, 파일 호환성·권한·서비스 조건의 변화를 우선한다. 위 작업은 관찰할
항목이며 모든 제품이 모두 제공한다는 뜻이 아니다.

## 제품과 발견 경로

- **Microsoft 365/Office Copilot**: Word·Excel·PowerPoint·Copilot Notebooks/Chat,
  OneDrive·SharePoint 연결을 앱별로 본다. 공식 릴리스 노트의 원래 날짜·플랫폼·
  배포 조건을 우선하고 공식 블로그/로드맵·지원 문서로 보완한다. 일반 Microsoft
  Copilot, Microsoft 365 Copilot과 앱별 기능/라이선스를 혼합하지 않는다.
- **Google Workspace**: Docs·Sheets·Slides·Drive와 Gemini/Notebook 계열의
  문서 작업·관리 기능을 기존 공식 업데이트 피드와 연결된 도움말에서 확인한다.
- **Adobe Acrobat**: AI Assistant·PDF Spaces·문서 생성/편집·공유와 관리 조건을
  공식 뉴스뿐 아니라 제품의 What's new·릴리스 노트·도움말에서 확인한다.
- **한컴·문서 AI 기업**: 한컴의 앱/에이전트, Upstage·사이냅·PolarisOffice 등의
  공식 제품/업데이트에서 편집·추출·검색·연계 범위의 변화를 찾는다. 사업 전략,
  전시 시연, 튜토리얼, 실제 제공과 고객 성과를 서로 구분한다.
- 새 문서 AI 도구도 실제 작업 범위와 파급이 확인되면 포함한다. 이 이름들은
  허용 목록이 아니며 커뮤니티는 발견 경로, 공식 원문은 사실 확인 경로다.

## 선정 항목에서 확인할 조건

1. 이전 기능과 비교해 무엇을 새로 할 수 있는지, 결과가 문서/셀/슬라이드에
   실제 반영되는지 또는 별도 답변/초안인지 확인한다. 인용·편집 보존·사용자 검토
   범위도 필요한 만큼 확인한다.
2. 발표일·원문 수정일, 베타/미리보기/일반 제공, 배포 시작과 완료를 구분한다.
   로드맵이나 오늘 읽은 오래된 도움말을 신규 출시로 알리지 않는다. 첫 연결 자료는
   기준선으로 삼고 같은 기능은 앱·플랫폼·출시 단계의 실제 변경 단위로 묶는다.
3. 앱/OS/Web·버전·배포 채널, 요금제/추가 라이선스·가격 조건, 한국어·지역,
   관리자 활성화·조직 권한, 파일 형식·크기/개수와 데이터 처리 조건을 대조한다.
   명시되지 않은 조건은 미확인으로 남긴다. 일반 제공도 전 테넌트 사용 보장이 아니다.
4. 공급자가 주장하는 효과와 독립 평가/실제 실행을 구분한다. 계정에서 실행하지
   않았으면 실제 동작 검증이라고 쓰지 않는다. 사내·개인 문서/메일을 사용하지 않고
   공개 제품 자료로 조사하며, 별도 요청 없는 앱 실행·문서 업로드·유료 API는 수행하지 않는다.

## 브리핑과 후속 리서치

기존 매일09:00 KST 브리핑에서 의미 있는 새/변경만 다른 주요 기술·사업 이슈와
함께 전달한다. 제품·기능과 원문 발표일, 달라진 문서 작업, 중요한 이용 조건·한계,
폴라리스의 공개 제품/사업 관점에서 검토할 의미와 공식 링크를1~3문장으로 정리한다.
변화가 없는 분야를 채우거나 모든 작은 업데이트를 개별 기록/발행하지 않는다.
중요한 문서 작업 변화는 커뮤니티 인기 점수만으로 제외하지 않는다.

심층 비교가 필요한 변화는 기존 글쓰기·품질 절차의 후속 조사로 연결한다. 단순 알림은
새 HTML/기사로 자동 발행하지 않는다. 제품 기능 추가만으로 새 기초 모델을 만들지 않고,
동일 소식은 모델/사업 예약과 중복 전달하지 않는다. 시간별 확인/수시 알림을 재개하지 않는다.

## 2026-10-23 연결 확인 범위

기존7개 일괄 목록과4개 브라우저 경로에 Microsoft 365 Copilot 릴리스 노트와
Acrobat What's new의 제품별 원문 검토 경로2개를 추가했다. `plan`/`collect`는
이2개를 `browser_required`로 명시한다. 자동 파싱이나 원문 검토 성공으로 표시하지 않는다.

Microsoft 공식 릴리스 노트의 개요·배포 방식·10월6일 묶음과 Word/Excel 등 관련
절을 읽었다. Adobe의 What's new는10월13일 수정 표기와 단계적 배포 안내, AI 도구
연결을 확인했다. 이 확인은 제품별 모든 기능/플랜·실제 계정 실행의 검증이 아니며,
새로 연결한 과거 항목을 오늘 출시로 통지하지 않았다. 직접 획득 결과/실패와 실제
독해 범위는 data/raw/research/2026-10-23-document-ai-scope/에 보존한다.
