# FDE 리서치의 네 가지 핵심 질문

Theo가 FDE를 먼저 학습하고 팀원에게 공유할 수 있도록, 역할과 필요성을 이해한 뒤 문서 기업의 고객 업무에 적용할 가능성을 논의하는 자료를 만든다.

## 요약

본문은 네 가지 질문으로 구성한다. 각 장 앞에는 발표에 사용할 핵심 정리와 도식을 두고, 뒤에는 개념·이유·실제 사례와 적용 예제를 설명한다. 고정된 장 수를 다른 리서치에 적용하는 규칙은 아니다. 최초의 8장·34항목 계획은 사용자 피드백으로 범위를 줄였으며 현재 집필 기준은 이 문서다. 변경 이유는 AI_RESEARCH_REVIEW_LOG의 FDE 목차 우선순위 기록에 남겼다.

## 독자와 학습 결과

- 독자: 일반적인 기업 서비스·문서 업무·AI 사용을 아는 개발자와 관리자. FDE·API·스키마는 모를 수 있다.
- 결과: FDE의 일과 최근 확대 이유를 설명하고, 문서 기업의 보유 기능을 고객의 입력·처리·결과에 연결해 팀과 논의할 수 있다.
- 제외: 독립 협업 조직 설명, 직무 준비·취업, 운영 지표 체계, 구현 프로젝트 계획서, 실제 고객 구축 실습.

## 시각 자료

요약 지도 1개와 장별 도식 4개를 제작한다. 역할의 적용·피드백 흐름, 제품 기능 이후 남는 연결, 사례별 문제와 결과, 가상 견적서의 입력·처리·결과를 표현한다. 조직 확대 발표를 업계 성장률 그래프로 만들지 않는다. 문서 기능 비교표는 4장 안에 둔다.

## 근거와 조건

- Palantir의 2020년 역할 설명은 그때 이미 존재했다는 증거다. 최초 탄생일이나 과거 중요도 하락은 입증하지 않는다.
- OpenAI DeployCo, AWS FDE, Atlassian의 조직 발표는 신설·확대와 투자 의지를 보여준다. 인수 종결·전체 시장 성장률·독립 효과를 확정하지 않는다.
- Adobe·Upstage의 공식 설명과 고객 사례는 기능과 업무 연결을 설명한다. 고객 내부 팀 사례에 공급사 FDE 파견을 임의로 붙이지 않는다.
- 견적서 주문 O1001·밸브 A 10개·확정 단가 50,000원·금액 500,000원은 부가세·추가 비용을 제외한 가정이다. 실제 API 실행·효과 측정은 하지 않았다.

## 검토와 산출물

현재 입력은 `config/fde_research.2026-10-12.r2.json`, 원문·분석·주장·검토 연결은 같은 이름의 quality JSON, 도식 연결은 `config/fde_visuals.2026-10-12.r2.json`이다. 새 불변 배치 `fde-learning-2026-10-12`와 안정 ID `fde-enterprise-adoption`을 사용한다. 새 수집기와 자동화는 추가하지 않는다.

제목·목적·요약을 먼저 자체 검토하고 본문 의미·원문 검토를 별도로 기록한다. 단일 작성 에이전트의 검토이며 독립 리뷰나 실제 초보 독자의 이해 시험으로 부르지 않는다. 기계 품질 검사·기존 자료 보존·모바일/데스크톱 출력은 별도 확인한다.

로컬 페이지는 `site/preview/fde-enterprise-adoption.html`, 공유용 단일 HTML은 `reports/fde-study-share.html`이다. r1은 보존하고 대화 의존 표현을 고친 `fde-reader-copy-2026-10-12` 배치가 현재 r2다. 공개 배포는 수행하지 않았다.

공유 파일 재생성: 먼저 로컬 `publish`로 스타일을 생성한 뒤 `python -m housing_watch.fde_share`를 실행한다. 입력·quality·출력 경로를 옵션으로 지정할 수 있다. 파일 안의 요약 복귀 링크는 공유 reader의 필수 DOM을 유지하며 사이트 목록으로 나가지 않는다. 목차·이미지·인쇄 스크립트와 글꼴·도식은 내장되어 있다. 앱 브라우저의 file:// 열기 정책과 일반 HTML 파일 생성·전달을 구분한다.
