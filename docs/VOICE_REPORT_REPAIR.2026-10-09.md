# 음성 기능 보고서의 설명 보강과 검토 기록

## 독자의 질문과 작업 범위

독자는 텍스트로 질문하면 업무 결과를 보여주는 AI 앱을 이미 가지고 있는 개발자다. 음성 기술을 처음 접한다고 가정한다. 독자의 질문은 “키보드 대신 말로 요청하고 싶다면 무엇을 추가해야 하는가?”다. 읽은 뒤 음성 입력만 필요한 경우, 답도 읽어줘야 하는 경우, 대화 도중 요청 변경이 필요한 경우를 구분하고, 기존 코드의 재사용 범위와 오류 확인 지점을 설명할 수 있어야 한다.

이번 작업은 `voice-agent-architectures` 한 편과 작성·검토 지침에 한정한다. 기존 33편과 모델 원문 14건은 재작성하지 않는다. 이전 음성 판본도 보존한다. 실제 녹음, 유료 API, SDK 연결, 속도·비용·한국어 정확도 측정과 실제 초보 독자 시험은 수행하지 않는다.

## 사용자 피드백으로 확인된 실패

본문의 비교 표는 구조와 제품 이름을 한 목록에 섞었다. 제목의 개수만 맞춰서는 비교가 성립하지 않는다. 반대로 사용자가 예시로 제안한 ‘음성 입력만 추가’와 ‘STT→AI→TTS’도 같은 축의 배타적인 구조는 아니다. 앞의 것은 기능 범위이고 뒤의 것은 처리 연결이다. 공식 문서의 실제 분류를 확인한 뒤 기능 요구와 역할 분담을 각각 설명하기로 했다.

이전 독립 에이전트의 Pass는 이해 가능성을 충분히 검증하지 못했다. 형식·근거·예제 존재 여부나 에이전트 판정은 사용자 승인과 실제 독자 검증을 대신하지 않는다.
