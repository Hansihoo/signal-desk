## 원인과 앞으로의 처리

일반 개발 동향 학습 글의 완결된 사례·응용 문제 규칙을 모델 소개에 적용했고,
기존 모델 운영 지침과 예약 문구도 사용 예시를 요구했다. 단순히 소제목만
고치면 다음 신규 모델에서 같은 문제가 반복된다.

- AGENTS, 작성 가이드, research-teaching과 substantive-review를 모델 소개 기준으로 연결했다.
- 생성의 plan/write/review 프롬프트와 실행 프로필에 `model_introduction`을 추가했다.
  이 유형은 이전 모델·경쟁 모델 비교, 장점과 단점, 사양·제공·가격 근거를 요구한다.
- `draft_issues`는 이 유형의 비교표 누락 및 example/code 블록을 거부한다.
  표가 실제 경쟁 비교인지, 장단점과 측정 조건이 타당한지는 독립 내용 검토에서 판단한다.
  문자열 검사로 모든 가상 예시나 오독을 자동 검출한다고 주장하지 않는다.
- [계획 템플릿](../config/ai_model_introduction.request.example.json)은 유료 호출 없이
  research-plan으로 검증했다. 실제 조사에서는 발표·모델 카드·가격·경쟁 원문을 추가한다.
- 기존 Editorial을 재사용한다. 두 수정 판에만 내용 해시를 등록해
  목적 → 요약 → 비교표 → 모델 분석 → 결론 순서로 보여준다.
  이전 판과 다른 유형의 화면 순서는 바꾸지 않는다.
- 매일 오전 5시 Asia/Seoul 예약 `ai`의 작성 지침을 갱신했다.
  이름·ACTIVE 상태·실행 시간·대상 채팅·인증 및 발행 범위는 보존했다.
  신규 모델에 활용 예시·가상 업무·실습·응용 문제를 넣지 않는다.

## 두 모델의 조사 범위

독자의 질문은 ‘새 모델은 이전 모델 및 경쟁 모델보다 무엇이 낫고 부족하며,
어떤 제공 조건에서 비교할 수 있는가’이다. 사용 절차나 가상 작업 성공을 가르치는
자료가 아니다. Wonder와 Full의 기존 report ID에 모델 소개 r2와
주제 분류 교정 r3를 추가하며 앞선 판은 보존한다. 로컬 화면 점검에서
임시 문장 정리 helper가 topic_path의 구분자까지 바꾼 것을 발견했다.
이미 적용한 r2를 덮어쓰지 않고 r3에서 기존 `AI 모델·API` 분류를 복원했다.
본문·수치·첫 화면은 r2와 같으며 교정 판의 경로 및 내용 동일성을 별도 검토한다.

비교군은 공식 카드의 GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5와
이전 계열 Spark 1.3이다. 사양·접근, 선택한 8개 평가 행, 표준 API 요금의 세 표를
분리했다. Spark는 카드의 공통 성능 행이 없어 임의 수치를 채우지 않는다.
Full의 월 구독료를 API 토큰 단가와 같은 업무 비용으로 비교하지 않는다.

Meta 발표·모델 목록·가격·구독·연구 소개·추론 문서와 카드,
OpenAI의 Astra 모델 문서, Anthropic의 Fable/Opus 모델 문서와 가격을 대조했다.
카드 p3 그림을 직접 보며 8행을 전사하고 p4–6의 측정 주체·추론·Harness,
p11–12의 한계를 읽었다. 운영 문서의 미표시 원 발행일을 추정하지 않았고
재사용한 발표·카드 원본의 최초/성공 수집 시각은 보존했다.

DeepSWE의 출처 혼재, SWE-Marathon의 Full xhigh와 경쟁 제품 Harness,
ProgramBench의 검사 95% 기준, MemoryBench의 64K–100K 토큰과 LLM 판정,
OSWorld의 부분 점수/완전 완료 및 Opus 결측, AA 지수의 단위를 설명했다.
유리한 코드 평가와 불리한 프로그램 재구성·터미널·종합 결과를 함께 적었다.

## 내용 검토와 시험

첫 화면은 본문을 주기 전에 독립 에이전트에게 검토했다. 두 번의 Revise에서
작업 용도, 평가 이름의 뜻과 단위, 가격 나열, preview와 Standard의 구분,
Everyday 대비 사용량 분모를 보완한 뒤 두 편이 Pass를 받았다.

최종 본문은 두 편 Pass를 받았다. r3는 본문이 같은 r2와 topic_path 교정만 대조해 Pass를 유지했으며, 원문을 새로 재획득했다고 주장하지 않는다.
