평가 항목과 비교 조건

AA Intelligence는 모델 평가입니다. Coding Agent Index는 Agent/Harness를 포함한 코딩 평가이며, CursorBench는 Cursor 환경에서 측정합니다. 점수·비용·토큰을 서로 다른 환경 사이에서 합치지 않습니다. Context는 수용량이고 저장소 이해나 무개입 완료율을 뜻하지 않습니다.

비율은 % 단위, 비용은 USD입니다. 최신 AA 모델의 파라미터 수는 B(10억) 단위입니다. 원본 표의 Q4/Q8/FP16 메모리는 추정치이며 KV cache·실행 환경 조건을 메모에서 확인하세요. SciCode는 원본에서 재검토 중인 평가입니다. 실제 작업의 무개입 완료율·회귀 없는 성공률·성공당 비용은 실측 자료가 있을 때만 표시합니다.

Theo의 공개 정리 자료를 가져온 기록입니다. 원자료 날짜는 최신 평가·제공 목록의 확인일, 이전 가이드의 기준일, 실사용 기록의 측정일입니다. 상세 정보에서 날짜의 종류를 확인하세요. 동기화 시각은 가져오기 시각입니다. 평가 실행일이 없는 경우 추정하지 않습니다.
